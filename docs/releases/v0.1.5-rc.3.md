# DeepSeek Harness Win7 v0.1.5-rc.3

本版对齐上游 `dsh-v0.1.5-rc.3`（`a4c74a91e06b00fe0b0937bde982170c526cc842`），发布冻结候选 `6cbcbf1c678b5f95d9498450fb6b5047c99d1bd0` 的原始产物。版本保持 rc.3，作为预发布提供；后续验收记录提交不改变产品标签身份。

## 下载与安装

[GitHub Release](https://github.com/czh869452912/deepseek-harness-win7/releases/tag/v0.1.5-rc.3) 提供七份发行产物和 SHA256SUMS.txt：

| 用途 | 64 位 Windows | 32 位 Windows |
| --- | --- | --- |
| Portable | `dsh-win7-portable-v0.1.5-rc.3.zip` | `dsh-win7-portable-v0.1.5-rc.3-x86.zip` |
| Desktop Standard | `dsh-desktop-standard-setup-v0.1.5-rc.3-x64.exe` | `dsh-desktop-standard-setup-v0.1.5-rc.3-x86.exe` |
| Desktop AIO | `dsh-desktop-aio-setup-v0.1.5-rc.3-x64.exe` | `dsh-desktop-aio-setup-v0.1.5-rc.3-x86.exe` |

`dsh-win7-offline-upgrade.zip` 为独立离线前置组件，不含应用。Win7 需 SP1；环境未准备好时选择 AIO，环境已就绪时选择 Standard，二者任选其一。安装器提示重启时，重启后再次运行。Portable 解压后使用 `dsh.bat --profile standard` 或 `dsh-web.bat`；Web 入口需要另有兼容浏览器，Desktop 自带内核。

客户端通过模型/服务商设置连接实际 LLM API，可配置内网地址、模型和密钥。发行包不附带测试数据或模拟服务。升级前从托盘退出应用，并备份整个 `DSH_HOME`（默认 `%USERPROFILE%\.dsh`）及自定义会话目录。详见[分发说明](../distribution.md)和[会话恢复指南](../session-upgrade-recovery.md)。

## 本版变化

- 推进 rc.3 canonical CLI、Web、会话格式和固定原版前端资源；桌面端使用 Electron22.3.27 与 Python3.8.10。
- 修复已有明文会话与默认 zstd 冲突导致的启动失败，CLI/Web/Desktop 共用默认历史编码保留策略；显式配置、自定义目录及混合格式保持严格校验。
- 修复启动父终端关闭后的 EPIPE 弹错，完善安装发布失败回滚、卸载保留用户文件及离线前置组件分发。
- 提供 x86/x64 Portable、Standard/AIO 和独立离线组件。更新客户端支持独立 HTTPS、私有 CA 和 Ed25519 签名；本版未配置实际自动更新通道。

## 验收与边界

同一候选已完成单次完整 x64 门禁：Python 19,367 通过/6 跳过、21 组固定 Source、82 个配对驱动及实际解压 Portable/现代与108浏览器验证。x86 另有实际包内运行、双浏览器三预设 fresh/cold 验证。四份桌面安装器完成六组实际管理员安装/升级/卸载旅程。真实 DeepSeek 消息、读文件工具和冷恢复覆盖两种架构 CLI 及 x64 Desktop；原版 renderer 完成120视图/60对比较。

2026-10-20，用户反馈：“已经完成了导入win7测试，没有观察到问题，进行这版的release”。该反馈对应此前交付的同候选普通离线导入包，作为用户 Win7 实测与发布授权记录。未收到逐项日志、系统位数、补丁/重启或浏览器矩阵，故不将其扩写为全部 Win7 组合的自动化认证。见[用户反馈记录](../../migration/evidence/HANDOFF-WIN7-RELEASE-20261020-6CBCBF1C.json)。

既有八项精确 Source 例外、C58 调度差异、原生表单约2 CSS px差异及 Python 插件 ABI/托盘/NSIS 等既定分发边界继续披露。`accepted_upstream` 保持 null，不代表任意插件或全部上游 ABI 全等。实际内网更新服务器和长期签名密钥留待用户部署，不影响手动下载安装。完整资格见[正式回执](../../migration/evidence/RUN-RC3-DESKTOP-COMPLETION-20261018-6CBCBF1C.json)与[完成记录](../research/2026-10-18-desktop-completion-validation.md)。

包内文档保留构建时快照，可能仍写有 Win7 待验证；当前状态以本发布说明和新增用户反馈记录为准。七份发行文件均保持原验收字节，不重新构建或重标为稳定版。
